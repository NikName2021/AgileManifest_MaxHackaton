# Проверка правок кабинета работодателя

Проверено 22 октября 2026 по `Правки_кабинета_работодателя_—_итог.pdf` и приложенному контракту бэкенда. Изменения находятся в рабочей ветке `codex/employer-cabinet-review`.

| Раздел PDF | Результат |
| --- | --- |
| 1. Общая оболочка | Верхняя панель убрана во всех кабинетах; роль под именем пользователя; тема рядом с выходом; мобильная навигация; счётчик новых откликов; общие статусы, кнопки, даты и тосты. |
| 2. Обзор | Убран из маршрутизации и меню, `/` ведёт на вакансии. Счётчики перенесены в фильтры и меню. |
| 3. Мои вакансии | Строки в общей карточке, фильтры с количеством, поиск только названия с задержкой, новые отклики выделены, остаток мест, копирование MAX-ссылки и переходы. |
| 4. Форма | Справочник сфер и серверные подсказки, свободный ввод и `categoryDetail`, общий селект регионов, поиск бейджей, лимит из API, группы с раскрытием, приватность контакта, ошибки под полями. |
| 5. Предпросмотр | Новый формат сообщения, контакт работодателя вынесен из публичного предпросмотра, действия публикации/QR/откликов/закрытия, ориентир зарплаты. Неопределённый результат доставки не выдаётся за успех. |
| 6. Отклики | Фильтры с количеством, компактные строки и диалог, копирование контакта, этап одним нажатием, защита от повторной записи при неопределённом результате. Универсальная ссылка MAX требует дополнения API — см. ниже. |
| 7. Команда | Строки сотрудников, надёжность, выбор опубликованной вакансии для приглашения, обработка результатов и повторная проверка неопределённой отправки. |
| 8. Профиль | Аккаунт, редактирование компании, прогресс подтверждённых выходов и оформление. |
| 9. Партнёр | Компактный канал, переключатель автопубликации, статистика, модалка всех фильтров и дайджеста. Переключатель отправляет частичный PATCH и сохраняет фильтры. |
| 10. Работник | Общая оболочка и палитра, чипсы этапов, даты, скрытый до приглашения контакт, категории подписок из общего справочника, отображение «Другое». |

## Проверки

- `npm run build` — успешно. Vite сообщает о JS-чанке больше 500 kB; сборку это не блокирует.
- `npm run lint` — успешно.
- Полный набор Vitest — **263 теста, 36 файлов, успешно**. После последних правок комбобокса и предпросмотра повторно пройдены 32 адресных теста.
- `git diff --check` — успешно.
- Playwright/Chromium: создание и сохранение черновика, выбор сферы и региона, бейдж, смена этапа и счётчик новых откликов, приглашение команды, сохранение компании, смена тем и ролей, фильтры/дайджест партнёра, справочник подписок работника.
- Desktop 1440×1000, tablet 834×1112 и mobile 390×844. На планшете и телефоне проверены вакансии, отклики, команда, профиль и форма; горизонтального переполнения страницы нет. Ошибок JavaScript не обнаружено.

## Граница проверки

Браузерные сценарии и скриншоты выполнены на локально запущенном приложении с демо-данными. API проверены по коду бэкенда, приложенному контракту и автоматическим тестам; это не проверка работающего production-сервера, отправки в настоящий канал или внешнего приложения MAX.

Кнопка «Написать в MAX» работает при наличии оставленной кандидатом ссылки MAX. Если оставлены телефон или почта, доступны соответствующие действия. Для универсальной ссылки независимо от контакта подготовлен [запрос к бэкенду](backend-employer-review-followup.md). Этот пункт нельзя считать полностью закрытым до появления подтверждённого адреса профиля/диалога в API.
